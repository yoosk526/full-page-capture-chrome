# 확인이 필요한 질문 (OPEN_QUESTIONS.md)

`docs/FEATURES.md`에서 **[미확인]**으로 남은 것, 그리고 만들면서 새로 생긴 궁금한 점을 모았습니다.
지금은 질문마다 **"지금 동작"**에 적은 가장 단순한 방식으로 만들어 두었습니다. 코드에는 `TODO(미확인)` 표시가 있습니다.
답을 정해 주시면(예: "Q3은 ②로") 그대로 고치겠습니다. 답하지 않은 질문은 지금 동작을 그대로 둡니다.

> 읽는 법: ①②③은 고를 수 있는 선택지입니다. **(지금)**이 붙은 것이 현재 만들어진 방식입니다.
