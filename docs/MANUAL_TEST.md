# 크롬에서 직접 확인하기 (MANUAL_TEST.md)

개발 환경(클라우드)에는 화면이 없어서 **사람이 직접 누르고 보는 동작**은 시험할 수 없었습니다.
그래서 자동 시험(E2E: 실제 크롬을 화면 없이 띄워 확장 프로그램을 올리고 자동으로 눌러 보는 시험)은 아래처럼 나눠서 했습니다.

| 자동 시험으로 확인한 것 (`npm run e2e`) | 사람이 직접 확인해야 하는 것 (이 문서) |
|---|---|
| 툴바 팝업의 고르는 창·페이지 전체·페이지 일부(영역 끌기·Esc 취소)(코드로 팝업을 열어 확인), 일괄 촬영, 스크롤 촬영·이어 붙이기(긴 페이지, 고정 머리글, 어두운 페이지, 내부 스크롤, 화면 배율 1·1.5·2), 결과 화면, 편집기 도구 10종·실행 취소·복제·자르기·도장·단축키 창, PNG·JPG·PDF 저장과 폴더, 복사 알림, 설정 저장, 바로 내려받기(19MB 파일 포함), 내 스크린샷 검색·선택·모두 저장·삭제, 보호 페이지 안내 | 사람이 아이콘·크롬 단축키를 눌러 시작, 진행 팝업의 모양과 일시정지(팝업 닫기), 실제 웹사이트, 인쇄 창, 다른 프로그램에 붙여넣기, 저장 위치 창, 내 컴퓨터 파일(file://) 촬영 |

> 자동 시험에서는 사람이 아이콘을 누르는 대신 코드로 팝업을 열거나 팝업과 같은 신호를 보냈습니다. 이때는 "누른 탭만 찍는 권한(activeTab)"이 생기지 않으므로, 시험용 복사본에만 "모든 사이트 접근" 권한을 잠시 더했습니다. 실제 설치본에는 이 권한이 없습니다. 그래서 **사람이 눌렀을 때 권한이 제대로 생기는지(1-1, 1-7)는 꼭 직접 확인해 주세요.**

준비: README의 "설치하기"대로 설치한 뒤, 툴바의 퍼즐 조각 아이콘(확장 프로그램 메뉴)에서 **한장캡처** 옆 핀을 눌러 툴바에 고정해 두세요.
각 항목을 해 보고 □에 ✔를 표시해 주세요. 결과가 다르면 항목 번호와 함께 알려 주세요.

## 1. 촬영 시작과 진행 팝업

- □ 1-1. 뉴스 기사처럼 긴 웹페이지를 열고 툴바의 한장캡처 아이콘을 누릅니다. → "무엇을 찍을까요?" 창이 뜨고, "페이지 전체"·"페이지 일부" 오른쪽에 단축키가 보입니다. "페이지 전체"를 누르면 진행 창으로 바뀌고 페이지가 저절로 스크롤됩니다.
- □ 1-1b. 아이콘 → "페이지 일부" → 페이지가 어둡게 덮입니다. 마우스로 사각형을 끌면 그 부분만 찍혀 결과 화면이 열립니다. Esc를 누르면 취소됩니다.
- □ 1-1c. 아이콘 → "내 스크린샷"은 내 스크린샷 화면을, "단축키 설정"은 크롬 단축키 화면을 엽니다.
- □ 1-2. 진행 팝업에 "페이지를 촬영하고 있어요", "3 / 7" 같은 조각 수, 막대, "가로 x 세로 px" 크기가 보입니다.
- □ 1-3. 끝나면 새 탭에 결과 화면("스크린샷 완성")이 열리고 페이지 전체가 한 장으로 보입니다. 원래 페이지는 처음 스크롤 위치로 돌아와 있습니다.
- □ 1-4. 촬영 중 팝업의 멈춤(❙❙) 버튼 → "잠시 멈춤"으로 바뀌고 스크롤이 멈춥니다. 다시 누르면 이어서 찍습니다.
- □ 1-5. 촬영 중 페이지의 빈 곳을 눌러 팝업을 닫습니다 → 촬영이 멈추고 페이지를 평소처럼 쓸 수 있습니다. 아이콘을 다시 누르면 이어서 찍습니다.
- □ 1-6. 촬영 중 "촬영 그만두기"를 누릅니다 → 팝업이 닫히고 결과 화면이 열리지 않습니다(부분 결과 없음).
- □ 1-7. 크롬 단축키 Ctrl+Shift+K(맥: ⇧⌘K) → 고르는 창 없이 바로 "페이지 전체" 촬영이 시작됩니다. Ctrl+Shift+E(맥: ⇧⌘E) → 바로 영역 고르기가 시작됩니다. (다른 프로그램이 같은 키를 쓰면 동작하지 않을 수 있습니다. 설정 화면의 "단축키 바꾸기"에서 바꿀 수 있습니다.)
- □ 1-8. 주소창에 `chrome://settings`를 열고 아이콘을 누릅니다 → 촬영하지 않고 "이 페이지는 크롬이 보호하고 있어요" 안내가 뜹니다. "예시 페이지에서 해 보기"는 example.com을 엽니다.
- □ 1-9. 크롬 웹 스토어 페이지에서도 1-8과 같은 안내가 뜹니다.

## 2. 여러 종류의 페이지

- □ 2-1. 위쪽에 고정된 메뉴(머리글)가 있는 사이트 → 결과에 머리글이 맨 위에 한 번만 나옵니다.
- □ 2-2. 어두운 테마 사이트 → 이어 붙인 곳이나 빈 곳이 흰색이 아니라 어두운 색입니다.
- □ 2-3. 내려가면서 그림이 늦게 나타나는 사이트 → 그림이 비어 있으면 설정에서 "이미지 기다리기"를 "최대 3초"로 바꾸고 다시 찍어 봅니다.
- □ 2-4. 웹 메일처럼 페이지 안의 한 영역만 스크롤되는 화면 → 그 영역의 내용이 끝까지 이어져 찍힙니다.
- □ 2-5. 아주 긴 페이지(스크롤바가 아주 작아지는 페이지) → 결과 화면 위에 "1 / 3번째 부분"처럼 나뉜 단추가 나오고 각각 볼 수 있습니다.
- □ 2-6. 내 컴퓨터의 HTML 파일을 크롬으로 열고 촬영 → 처음에는 "파일 URL에 대한 액세스 허용을 켜 주세요" 안내가 나옵니다. 확장 프로그램 관리 화면에서 한장캡처의 "세부정보" → "파일 URL에 대한 액세스 허용"을 켜면 찍힙니다.
- □ 2-7. (맥 레티나 화면 등) 화면 배율이 높은 컴퓨터 → 결과 크기가 화면 크기의 2배쯤(예: 2560 x …)이고 글자가 선명합니다.

## 3. 결과 화면

- □ 3-1. 오른쪽 아래 −, +, 맞춤 버튼으로 크기를 바꿀 수 있고 비율(예: 27%)이 표시됩니다.
- □ 3-2. "PNG로 저장"을 누르면 다운로드 폴더에 `screencapture-사이트주소-경로.png` 파일이 생깁니다.
- □ 3-3. 저장 버튼 옆 ▾를 눌러 JPG, PDF로도 저장해 봅니다. PDF를 열면 페이지가 보입니다.
- □ 3-4. "복사"를 누른 뒤 카카오톡, 워드, 구글 문서 등에 붙여넣기(Ctrl+V / ⌘V) → 그림이 붙습니다.
- □ 3-5. "인쇄"를 누르면 인쇄 창이 뜨고 미리보기에 스크린샷이 보입니다.
- □ 3-6. 폴더 아이콘 → 내 스크린샷, 톱니 아이콘 → 설정, 말풍선 아이콘 → 오류 신고(이 저장소의 이슈 페이지)가 열립니다.
- □ 3-7. 휴지통 → "이 스크린샷을 지울까요?" 확인 창 → 확인하면 지워지고 내 스크린샷 화면으로 갑니다.

## 4. 편집기

- □ 4-1. 결과 화면의 "편집" → 편집 화면이 75% 크기로 열립니다. 왼쪽에 도구 12개가 있고, 도구 위에 마우스를 올리면 이름과 단축키가 나옵니다.
- □ 4-2. 사각형(R), 타원(O), 화살표(A), 선(L)을 끌어서 그립니다. 오른쪽 "개체" 목록에 하나씩 추가됩니다.
- □ 4-3. 텍스트(T): 그림 위를 누르고 한글을 입력한 뒤 바깥을 누릅니다 → 글자가 남습니다. 선택 도구(V)로 글자를 두 번 누르면 고칠 수 있습니다.
- □ 4-4. 번호(N): 그림 위를 여러 번 누릅니다 → 1, 2, 3이 차례로 만들어집니다.
- □ 4-5. 가리기(B): 글자가 있는 곳을 끌어 덮습니다 → 글자를 읽을 수 없게 흐려집니다. 오른쪽에서 "모자이크"로 바꾸면 네모 블록이 됩니다.
- □ 4-6. 형광펜(H), 펜(P)으로 자유롭게 그립니다. 형광펜 아래의 글자가 비쳐 보입니다. (붓은 없앴습니다)
- □ 4-6b. Shift를 누른 채 사각형·타원을 끌면 정사각형·정원이, 선·화살표를 끌면 수평 또는 수직선이 그려집니다.
- □ 4-6c. 그리기 도구를 쓰다가 Esc를 누르면 선택 도구로 바뀝니다.
- □ 4-6d. 오른쪽 개체 목록에서 Shift를 누른 채 여러 줄을 누르면 함께 골라지고, 함께 지우기·옮기기·복제·색 바꾸기가 됩니다.
- □ 4-7. 선택 도구(V)로 개체를 누르면 핸들(작은 네모)이 나오고, 끌어서 옮기거나 핸들로 크기를 바꿀 수 있습니다. 오른쪽에서 색·두께·채우기를 바꿉니다.
- □ 4-8. 화살표 키로 1칸씩, Shift+화살표로 크게 옮겨집니다. Ctrl+D(⌘D) 복제, Delete 지우기가 됩니다.
- □ 4-9. 개체 목록에서 고른 줄의 ↑(앞으로 가져오기), ↓(뒤로 보내기), ✕(지우기)가 동작합니다.
- □ 4-10. Ctrl+Z(⌘Z) 실행 취소, Ctrl+Y(⌘Y) 다시 실행. 처음 열었을 때는 두 버튼이 회색입니다.
- □ 4-11. 자르기(C): 테두리의 핸들을 끌어 영역을 고르고 Enter(또는 "자르기 적용") → 잘립니다. Esc(또는 "취소")는 그대로 둡니다.
- □ 4-12. 더보기(…) → 주소와 날짜 표시에서 "위쪽 띠", "아래쪽 띠", "Mac 브라우저 창", "Windows 브라우저 창"을 차례로 골라 모양을 봅니다. 날짜 형식 4가지도 바꿔 봅니다. U 키로 켜고 끌 수 있습니다.
- □ 4-13. Shift+? 또는 더보기 → 단축키 → 단축키 창이 뜹니다.
- □ 4-14. Z 확대, Alt+Z(Option+Z) 축소, Ctrl+휠(⌘+휠) 확대/축소가 됩니다.
- □ 4-15. 편집 후 Ctrl+E(⌘E) → 바로 저장, Ctrl+Shift+E → 저장 위치 창, Ctrl+Alt+E(⌘⌥E) → 클립보드 복사. 저장한 파일에 편집 내용이 들어 있습니다.
- □ 4-16. 뒤로(←)를 누르면 결과 화면에 편집 내용이 그대로 보입니다.

## 5. 설정

- □ 5-1. 아이콘을 오른쪽 클릭 → "옵션"을 누르면 설정 화면이 열립니다.
- □ 5-2. 파일 형식을 JPEG로 바꾸면 결과 화면의 저장 버튼이 "JPG로 저장"으로 바뀝니다.
- □ 5-3. "폴더에 저장"에 `screenshots`를 쓰고 저장 → 이후 파일이 다운로드 폴더 안 screenshots 폴더에 저장됩니다. `a/b`나 `..`를 쓰면 빨간 안내가 나옵니다.
- □ 5-4. "저장할 때마다 위치 묻기"를 켜면 저장할 때 저장 위치 창이 뜹니다.
- □ 5-5. "파일 자동 다운로드"를 켜고 촬영 → 결과 탭이 열리지 않고 파일이 바로 저장되며, 팝업에 "파일로 내려받았어요"가 나옵니다. (끝나면 다시 꺼 두세요.)
- □ 5-6. PDF 용지를 A4로 바꾸고 긴 페이지를 PDF로 저장 → 여러 쪽으로 나뉘고, 나뉜 곳에서 글자가 잘리지 않습니다. 링크를 누르면 해당 사이트가 열립니다. "첫 페이지 위에 주소와 날짜 넣기"를 켜면 첫 쪽 맨 위에 주소와 시각이 들어갑니다.
- □ 5-7. 아주 긴 스크린샷을 복사해 구글 문서에 붙여넣기 → 붙여넣어지고, "줄인 크기로 복사했어요" 알림이 나옵니다.

- □ 5-8. PDF 용지에서 "전체 이미지"가 아닌 것(A4 등)을 고르고 방향을 "가로"로 바꾼 뒤 PDF로 저장 → 가로로 긴 용지로 저장됩니다. "전체 이미지"를 고르면 방향 선택이 흐려집니다.
- □ 5-9. "촬영 단축키"에 세 가지(도구 창 열기 / 페이지 전체 찍기 / 페이지 일부 골라 찍기)와 지금 키가 보입니다.

## 6. 내 스크린샷

- □ 6-1. 지금까지 찍은 스크린샷이 4열 카드로 보이고 맨 앞이 가장 최근 것입니다. 카드 아래에 "사이트, 가로x세로, 10월 8일 23:54" 같은 정보가 있습니다.
- □ 6-2. 카드에 마우스를 올리면 크게 보기·편집·지우기 아이콘이 나오고 각각 동작합니다.
- □ 6-3. 검색 칸에 제목이나 주소 일부를 쓰면 맞는 카드만 남습니다.
- □ 6-4. "전체 선택" → 모든 카드에 체크, 아래에 "선택됨: N" 막대. 카드를 누르면 하나씩 빠집니다.
- □ 6-5. "모두 저장: N" → 고른 개수만큼 파일이 하나씩 따로 저장됩니다(압축 파일 아님).
- □ 6-6. "지우기" → 확인 창 → 고른 스크린샷이 사라지고 보관 개수가 줄어듭니다.
- □ 6-7. 크롬을 껐다 켜도 스크린샷이 남아 있습니다.

## 6-2. 일괄 촬영

- □ 6-8. 내 스크린샷 → 검색창 옆 겹친 사각형 아이콘 → 일괄 촬영 화면이 열립니다.
- □ 6-9. "열린 탭 추가" 또는 "시작"을 처음 누르면 크롬이 "모든 사이트" 접근 허락을 묻습니다. 허락하면 계속됩니다.
- □ 6-10. 주소 2~3개를 한 줄에 하나씩 넣고 "시작" → 앞쪽에 새 창이 열려 하나씩 찍고, 끝나면 창이 닫히며 "끝났어요. 성공 N개"가 나옵니다. 찍은 것은 내 스크린샷에 들어갑니다. (찍는 동안 그 창을 다른 창으로 가리지 마세요)
- □ 6-11. 진행 중 "그만두기"를 누르면 멈추고 창이 닫힙니다.

## 7. 개인정보

- □ 7-1. 인터넷을 끊은 상태(와이파이 끄기)에서도 촬영·편집·저장이 모두 됩니다.
