## 7. Issue #3: 페이지 일부 찍기에서 자동 스크롤이 안 됨 (2026-10-09)

- 요청 위치: https://github.com/yoosk526/full-page-capture-chrome/issues/3
- 원인(재현함): 글 본문이 페이지 안의 틀(iframe) 안에서 스크롤되는 사이트(네이버 블로그 등)에서는 바깥 페이지도, 찾던 스크롤 상자도 움직이지 않아 자동 스크롤이 0px였다. 같은 이유로 "페이지 전체 찍기"도 첫 화면만 찍힐 수 있었다.
- 고침: 같은 사이트의 틀이면 그 안의 문서를 스크롤한다. "페이지 일부"의 자동 스크롤과 긴 영역 이어 찍기, "페이지 전체"의 스크롤 촬영 모두 적용.
- 후속 신고(스크롤은 되지만 손을 떼면 "찍지 못했어요"): 확장 프로그램을 업데이트(↻)하기 전부터 열려 있던 탭에는 옛 버전이 남긴 "준비됨" 표시만 있고 응답할 코드는 끊겨 있었다. 새 버전이 그 표시만 보고 준비를 건너뛰어 촬영 쪽이 페이지와 연결되지 못했다. 이 상태를 시험에서 재현해 실패를 확인했고, 넣을 때마다 받는 쪽을 새로 걸도록 고쳤다. 실패 안내에 "새로고침(F5)한 뒤 다시 해 보세요"를 덧붙였다.
- TODO(추정): 다른 사이트에서 불러온 틀(예: 광고, 외부 동영상)은 브라우저가 안을 볼 수 없게 막으므로 스크롤하지 못한다.
