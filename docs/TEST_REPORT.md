- E2E는 실제 크롬에 빌드 결과를 올려 촬영, 이어 붙이기, 보관, 결과 화면, 편집기, 저장, 복사, 설정, 바로 내려받기, 내 스크린샷, 보호 페이지 안내를 확인합니다. 저장된 이미지의 픽셀 색까지 읽어 머리글 반복, 맨 아래 누락, 어두운 바탕, 스크롤 막대 여부를 검사합니다.
- E2E로 할 수 없는 것: 사람이 툴바 아이콘을 눌렀을 때 생기는 권한(activeTab), 인쇄 창, 다른 프로그램에 붙여넣기, 저장 위치 창, 내 컴퓨터 파일(file://) 권한, 실제 인터넷 사이트. 이 클라우드 환경은 바깥 사이트에 접속할 수 없고 화면도 없기 때문입니다. 이 항목들은 `MANUAL_TEST.md`에 넣었습니다.

## 3. 커버리지 (참고 수치)

커버리지(테스트가 코드의 몇 %를 실행했는지)는 목표로 삼지 않았고 참고로만 적습니다. (`npm run coverage`)

| 범위 | 줄 | 분기 | 함수 |
|---|---|---|---|
| 순수 계산 `src/core/` 전체 | 93.1% | 86.2% | 90.1% |

- **전체 수치가 낮은 이유**: 화면(`src/pages/`), 서비스 워커(`src/background/`), 페이지 안 코드(`src/content/`), 그리기(`src/render/`)는 크롬 API·캔버스·실제 브라우저가 있어야 의미 있게 시험할 수 있습니다. 가짜 크롬 API로 단위 테스트를 만들면 구현을 베끼는 테스트가 되기 쉬워, 이 부분은 단위 테스트 대신 **E2E**(실제 크롬)로 확인했습니다.
