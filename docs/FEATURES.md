# 기능 명세 (FEATURES.md)

직접 만들 "전체 페이지 스크롤 캡처 + 편집기" 크롬 확장 프로그램의 기능 목록이다.
기존 상용 확장 프로그램 **FullPage Capture - Full Page Screenshot**(이하 "기존 프로그램")의 동작을 화면과 공개 설명으로 관찰해 정리했다.

## 0. 문서 정보

- 1차 작성: 2026-10-08 / 2차, 3차, 4차 갱신: 2026-10-09
  - 4차에서 바뀐 것: 편집기 주황 안내 띠는 구현하지 않기로 함, 번호 표시는 만들 때마다 숫자가 올라감, "전체 저장"은 파일을 하나씩 저장, 10번 항목을 확정 방침으로 정리
  - 3차에서 추가한 것: 형광펜·펜·브러시 패널, 주소·날짜 도장 5가지의 실제 모양, 모자이크 모드, 개체 앞으로 가져오기, 내 스크린샷 선택 모드, 스크린샷 삭제 확인 창, 촬영 중지 동작
  - 2차에서 추가한 것: 설정 화면 전체, "내 스크린샷" 화면, 편집기 더보기(…) 메뉴, 타원·선·텍스트 패널, 전체 단축키 목록, 크롬 단축키 항목, 캡처 불가 페이지 안내, Pro 구분 보강
- 조사 대상: 웹스토어 표기 버전 1.19.64 (2026-10-02 갱신). 실제로 설치된 버전은 확인하지 못했다.
- 웹스토어 주소: https://chromewebstore.google.com/detail/fullpage-capture-full-pag/ggacghlcchiiejclfdajbpkbjfgjhfol
- 근거 표기
  - **[확인]** 실제 사용 화면(스크린샷) 또는 사용자가 직접 설명한 동작
  - **[공식]** 웹스토어 설명에만 있고 화면은 아직 못 봄
  - **[추정]** 아이콘이나 문구로 짐작한 것. 동작은 보지 못함
  - **[미확인]** 존재 여부나 동작을 아직 모름
  - **[제안]** 새 프로그램의 구현 방침. 10번 항목과 함께 기본 방침으로 확정되었다(사용자 이의 없음). 바꾸려면 사용자가 이 문서를 고친다.
- 요금 표기: **[무료]** / **[Pro]** (기존 프로그램의 유료 구분. 이번에 만드는 프로그램은 전부 무료로 구현한다.)

### 클로드 코드에게 (구현 원칙)

1. 이 문서의 [확인]과 [공식] 항목은 구현 대상이다. [추정] 항목은 가장 단순한 동작으로 구현하되 코드에 `TODO(추정)`을 남긴다.
2. [미확인] 항목은 임의로 결정하지 말고 `docs/OPEN_QUESTIONS.md`에 질문으로 적는다. 구현이 막히면 가장 단순한 기본 동작을 쓰고 코드에 `TODO(미확인)`으로 표시한다.
3. 기존 프로그램의 소스 코드는 열람하거나 복제하지 않는다. 이름, 로고, 아이콘, 문구는 쓰지 않고 새로 만든다. (UI 문구는 한국어 기본, 새로 작성) 이 문서에 따옴표로 적힌 화면 문구는 기능을 설명하려고 옮긴 것이지 그대로 쓰라는 뜻이 아니다.
4. 기본값과 관찰값은 "관찰한 시점의 선택값"이며, 처음 설치했을 때의 기본값인지는 모른다.
5. [제안]으로 표시된 방침과 10번 항목의 방침은 확정된 것으로 보고 따른다. 1단계에는 10번 항목의 "1단계" 범위만 만든다. 2단계 기능과 제외 기능은 사용자가 따로 요청하기 전에는 만들지 않는다.

## 1. 전체 흐름

1. 툴바 아이콘 클릭 → 확인 화면 없이 곧바로 촬영 시작 [확인] (크롬 단축키로도 시작, CAP-01)
2. 촬영 진행 팝업 표시 [확인]
3. 새 탭에 결과 화면("스크린샷 완성") 표시 [확인]
   - 설정의 "파일 자동 다운로드"가 켜져 있으면 결과 탭 없이 이미지 파일이 곧바로 내려받아진다. [확인: 설정 안내문]
4. "편집" 버튼 → 편집기("마크업") 진입, 도구로 편집 후 뒤로가기 [확인]
5. 저장 / 복사 / 인쇄 / Drive 저장 [확인]
   - 저장 버튼을 누르면 설정에 저장해 둔 파일 형식으로 곧바로 저장되고, 저장 위치를 고르는 창이 뜬다. [확인: 사용자 설명]
6. 촬영한 이미지는 이 기기에 보관되고 "내 스크린샷" 화면에서 다시 열 수 있다. [확인]

**진행 팝업 구성 [확인]**
- 상태 문구: "페이지를 찍는 중" (앞에 상태 표시 점)
- 진행 조각 표시: "3 / 4", "1 / 2"처럼 (현재 조각 / 전체 조각), 오른쪽에 일시정지 아이콘 버튼
- 단계 이름: "스크롤 중". 그 아래 진행 막대
- 결과 크기 표시: "2560 x 4318 px", "2560 x 1353 px"처럼
- 안내문: "닫으면 일시중지, 다시 열면 계속됩니다"
- 왼쪽에 페이지 모양의 썸네일, 아래에 "촬영 중지" 버튼(× 아이콘)

**캡처 불가 페이지 [확인]**
- 설정 화면이나 웹 스토어 같은 브라우저 보호 페이지에서 아이콘을 누르면 촬영이 시작되지 않고 안내 팝업이 뜬다.
- 팝업 구성: 위쪽에 프로그램 이름, 눈에 사선이 그어진 아이콘, 굵은 제목 "Chrome이 이 페이지를 보호합니다", 설명 "설정이나 웹 스토어 같은 브라우저 페이지는 보호되어 있어 어떤 확장 프로그램도 찍을 수 없습니다. 일반 사이트에서는 모두 잘 작동합니다."
- 버튼 2개: "예시 페이지에서 사용해 보기"(강조색, 카메라 아이콘), "닫기"(× 아이콘)
- "예시 페이지"가 어디로 연결되는지는 [미확인]
- 어떤 주소까지 막히는지의 정확한 목록은 [미확인]. 적어도 `chrome://` 계열과 웹 스토어는 막힌다. [확인]

**관찰 메모**
- 결과 폭이 2560px이다. 화면 배율(devicePixelRatio 2)이 반영된 값으로 추정하지만 확인하지 못했다. 내 스크린샷에는 폭 1440, 1441, 1309, 1710처럼 다른 값도 있다. 폭이 홀수(1441)인 경우도 있다.
- 조각 수는 "전체 높이 ÷ 한 화면 높이"를 올림한 값으로 추정한다. 관찰: 4318px는 4조각, 1353px는 2조각. [추정]
- 단계 이름이 "스크롤 중"인 것으로 보아 이어 붙이는 단계 등 다른 단계가 더 있을 수 있다. [미확인]

## 4. 편집기 "마크업" (EDT)

결과 화면의 "편집" 버튼으로 들어간다. "내 스크린샷"의 카드에서도 들어갈 수 있는 것으로 보인다(GAL-03).

### 4-1. 화면 구성 [확인]

- 상단 왼쪽: 뒤로가기, 제목 "마크업", 실행취소, 다시실행
- 상단 가운데: 축소(−), 확대 비율(예: 75%, 36.0%), 확대(+), 화면 맞춤
- 상단 오른쪽: 복사, 인쇄, Save to Drive, Save as PNG(드롭다운), 더보기(…)
- 왼쪽 세로 도구 막대, 가운데 캔버스
- 오른쪽 패널: 위는 선택한 개체의 스타일, 아래는 "개체" 목록
- 맨 아래 상태 표시줄: 왼쪽에 "이미지 크기 px, 개체 N objects", 오른쪽에 원본 페이지 주소
- 왼쪽 아래 구석에 말풍선 모양 아이콘(문제 신고로 추정)
- 화면 맨 위에 주황빛 안내 띠(영문)가 뜨는 경우가 있다. 사용자 결정에 따라 **구현하지 않는다.** 편집 내용의 반영은 RES-08에 적힌 관찰(편집기에서 돌아오면 결과 화면 미리보기에 그대로 보임)을 따른다.

### 4-3. 도구별 동작과 속성

색 목록은 모든 도구가 같다. 7가지: 검정(짙은 남색에 가까움), 빨강, 노랑, 초록, 회청색, 흰색, 사용자 지정(무지개 아이콘). 채우기 목록은 8가지: 사용자 지정, 없음(사선 아이콘), 검정, 빨강, 노랑, 초록, 회청색, 흰색.

**EDT-01 선택과 편집 [확인]**
- 개체를 선택하면 모서리와 가장자리에 크기 조절 핸들이 표시된다.
- 선택하지 않았을 때 오른쪽 패널에는 "스타일을 바꿀 개체를 선택하세요."가 나온다.

**EDT-02 자르기 [확인]**
- 이미지 둘레에 핸들 8개(모서리 4, 변 중앙 4)와 3분할 격자선이 표시된다.

## 6. 요금 구분 (기존 프로그램)

편집한 상태에서 저장 버튼을 누르면 "계속하려면 Pro 무료 체험을 시작하세요" 창이 뜬다. [확인]

- 안내 문구 요지: 편집 내용이 담긴 스크린샷의 저장은 Pro 기능이다. 페이지를 그대로 찍은 스크린샷은 지금처럼 무료로 저장, 복사, 인쇄할 수 있다.
- 편집한 상태에서 **JPG 저장, PDF 저장, 복사, 인쇄도 모두 같은 Pro 안내가 뜬다.** [확인: 사용자 설명] Save to Drive와 단축키(Cmd+E 등)는 [미확인]
- Pro 혜택 목록과 설정 화면의 대응
  1. 편집 내용을 그대로 파일에 저장 → 위의 저장 차단 (새 프로그램은 막지 않는다)
  2. 검색, 선택, 복사가 가능한 PDF → SET-31 검색 가능한 PDF
  3. 내보낸 파일에 주소, 시각, 체크섬 표시 → SET-30 증거 모드
  4. 페이지 목록을 한 번에 촬영 → SET-32 일괄 촬영
  5. 내 Google Drive에 바로 저장 → SET-33 Google Drive
- 가격: 첫 7일 무료 체험, 이후 연 $19 (참고용 정보)
- 편집 도구를 쓰는 것 자체는 막히지 않았다. 막히는 지점은 "편집 내용이 포함된 저장"이다.

## 10. 확정 방침

설정 화면으로 Pro 기능의 정체가 대부분 드러났다. 아래 방침으로 확정해 진행한다(2026-10-09, 사용자 이의 없음). 바꾸고 싶으면 이 표를 고친다.

| 번호 | 기능 | 방침 | 이유 |
|---|---|---|---|
| 1 | 기본 기능 (캡처, 결과 화면, 편집기 12개 도구, PNG/JPG/PDF 저장, 복사, 인쇄, 주소·날짜 도장, 설정, 내 스크린샷) | **1단계에 구현** | 기존 프로그램에서 무료로 쓰던 범위와 편집 저장 차단 해제분 |
| 2 | 검색 가능한 PDF (SET-31), 증거 모드 (SET-30), 일괄 촬영 (SET-32) | **2단계에 구현** | 구글 계정 없이 만들 수 있지만 1단계보다 복잡하고, 일괄 촬영은 화면을 아직 못 봤다. 증거 모드의 검증 화면은 외부 사이트가 아니라 확장 프로그램 안에 만든다. |
| 3 | Google Drive 저장 (EXP-07, SET-33) | **제외** | 구글 로그인 승인 절차와 앱 등록이 필요하다. 기존 프로그램의 "네트워크 요청 없음" 방침과도 어긋난다. 필요해지면 따로 상의한다. |
| 4 | 계정 로그인, Pro 안내 창, 체험 버튼 (SET-05, RES-07) | **제외** | 모든 기능이 무료라서 필요 없다. |
| 5 | 문제 신고 (설정 화면, 더보기 메뉴) | **저장소의 이슈 페이지 링크로 대체** | 기존 프로그램의 신고 창구는 쓸 수 없다. |
| 6 | 구현 순서 | **캡처(CAP) → 편집기(EDT) → 내보내기(EXP) → 설정과 단축키(SET) → 내 스크린샷(GAL) → 2단계** | 앞서 정한 A→B→C→D 단계 뒤에 GAL과 2단계를 붙인다. 촬영 결과를 기기에 보관하는 구조는 CAP 단계에서 함께 만든다. |

## 11. 아직 확인하지 못한 화면

1차 문서가 요청한 12개 화면은 대부분 확인했다. 남은 항목은 개발을 막지 않으므로, 개발 중 `docs/OPEN_QUESTIONS.md`로 넘겨도 된다.

**있으면 좋은 것**
- 없음. 더 요청할 화면은 없다.

**건너뛰어도 되는 것**
1. 설정 드롭다운(스크롤 사이 대기, 이미지 기다리기)의 선택지 목록
2. 결과 화면의 별, 말풍선 버튼의 동작
3. 일괄 촬영 화면 (Pro 체험을 시작해야 보인다)
4. 높이 약 2만 px 이상의 긴 페이지를 찍었을 때 분할 결과

**4차에서 해결된 항목**
- 편집기 주황 안내 띠(구현하지 않기로 함), 번호 표시 자동 증가, 전체 저장(파일을 하나씩 저장)

**3차에서 해결된 항목**
- 형광펜·펜·브러시 패널, URL on bottom·Mac 브라우저·Windows 브라우저 도장 모양, 모자이크 모드, 개체 "앞으로 가져오기", 내 스크린샷 선택 모드, 스크린샷 삭제 확인 창, 촬영 중지(그냥 취소)

**2차에서 해결된 항목**
- 툴바 클릭 직후 화면(없음, 곧바로 촬영), 설정 화면, 폴더 버튼(내 스크린샷), 더보기 메뉴, 타원·선·텍스트 패널, 단축키 목록, 크롬 단축키 항목, 캡처 불가 페이지, Pro 차단 범위, 자르기 숫자 입력(없음), 주소·날짜 도장 위치, PDF 용지 선택 위치(설정 화면)
