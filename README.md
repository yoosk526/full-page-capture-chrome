# 한장캡처 — 전체 페이지 스크롤 캡처 + 편집기 (크롬 확장 프로그램)

웹 페이지를 **위에서 아래까지 저절로 스크롤하며 찍어 한 장의 이미지로** 만들어 주는 크롬 확장 프로그램입니다.
찍은 뒤에는 화살표·글자·번호를 넣거나, 개인정보를 흐리게 가리거나, 필요한 부분만 잘라서 PNG·JPG·PDF로 저장할 수 있습니다.

- 계정 가입이 필요 없습니다.
- 사용 기록을 모으지 않습니다(분석 도구 없음).
- 인터넷으로 아무것도 보내지 않습니다. 찍은 이미지는 **이 컴퓨터 안에만** 보관됩니다.
- 워터마크(이미지에 찍히는 상표 글자)를 넣지 않습니다.

> 이 프로그램은 기존 상용 확장 프로그램의 **기능만** 참고해 처음부터 새로 만들었습니다. 그 프로그램의 코드, 이름, 로고, 화면 문구는 쓰지 않았습니다. 기능 기준은 [`docs/FEATURES.md`](docs/FEATURES.md)입니다.

## 설치하기 (처음 한 번)

크롬 웹 스토어에 올린 프로그램이 아니므로, 압축 파일을 받아 직접 설치합니다. 5분이면 됩니다.

1. **압축 파일 받기**: 이 저장소의 `release` 폴더에 있는 `hanjang-capture-v1.0.0.zip` 파일을 내려받습니다.
   (GitHub 화면에서 파일 이름을 누른 뒤 오른쪽의 내려받기(↓) 버튼을 누르세요.)
2. **압축 풀기**: 내려받은 파일을 오른쪽 클릭 → "압축 풀기"(맥은 두 번 클릭)를 합니다.
   `hanjang-capture-v1.0.0`이라는 폴더가 생깁니다. 이 폴더는 **지우거나 옮기지 말고** 문서 폴더처럼 오래 둘 곳에 두세요. (크롬이 이 폴더에서 프로그램을 읽습니다.)
3. **확장 프로그램 관리 화면 열기**: 크롬 주소창에 `chrome://extensions`를 입력하고 Enter를 누릅니다.
   (또는 크롬 오른쪽 위 ⋮ 메뉴 → 확장 프로그램 → 확장 프로그램 관리)
4. **개발자 모드 켜기**: 화면 오른쪽 위의 **"개발자 모드"** 스위치를 켭니다.
   - "개발자 모드"는 웹 스토어를 거치지 않은 프로그램을 직접 설치할 수 있게 해 주는 크롬 설정입니다.
5. **프로그램 올리기**: 왼쪽 위에 새로 나온 **"압축해제된 확장 프로그램을 로드합니다"** 버튼을 누르고, 2번에서 만든 `hanjang-capture-v1.0.0` 폴더를 고른 뒤 "선택"(맥은 "열기")을 누릅니다.
   - 폴더 **안으로 들어가지 말고**, 폴더 자체를 골라야 합니다. 그 폴더 안에 `manifest.json` 파일이 보이면 맞는 폴더입니다.
6. 목록에 **"한장캡처"**가 나타나면 설치가 끝났습니다.
7. (권장) 크롬 툴바의 퍼즐 조각 아이콘을 누르고, 한장캡처 옆의 핀(📌)을 눌러 툴바에 고정하세요.
8. (선택) 내 컴퓨터에 있는 HTML 파일도 찍으려면, 관리 화면의 한장캡처 **"세부정보"** → **"파일 URL에 대한 액세스 허용"**을 켜세요.

크롬을 켤 때 "개발자 모드 확장 프로그램을 사용 중지하세요" 같은 안내가 나올 수 있습니다. 직접 설치한 프로그램이라 나오는 안내이니 **"취소"(또는 닫기)**를 누르면 됩니다.

## 업데이트하기 (새 버전이 나왔을 때)

1. 새 압축 파일(예: `hanjang-capture-v1.1.0.zip`)을 내려받아 압축을 풉니다.
2. 기존 폴더(`hanjang-capture-v1.0.0`) 안의 파일을 모두 지우고, 새로 푼 폴더 안의 파일을 그 자리에 넣습니다. (폴더 이름과 위치를 그대로 두는 것이 핵심입니다.)
3. `chrome://extensions`에서 한장캡처 카드의 **새로고침(↻) 버튼**을 누릅니다.
4. 버전 숫자가 바뀌었는지 확인합니다.

- 이렇게 하면 **지금까지 찍어 둔 스크린샷과 설정이 그대로 남습니다.**
- 주의: 관리 화면에서 한장캡처를 **"삭제"**하면 보관된 스크린샷도 함께 지워집니다. 필요한 스크린샷은 먼저 "내 스크린샷 → 전체 선택 → 모두 저장"으로 파일로 내려받아 두세요.
- 다른 위치에 새 폴더를 만들어 "압축해제된 확장 프로그램을 로드합니다"로 다시 올리면 **다른 프로그램으로 취급**되어 이전 스크린샷이 보이지 않습니다.

## 요청하는 권한과 이유

확장 프로그램이 할 수 있는 일은 "권한"으로 정해집니다. 필요한 것만 요청합니다.

| 권한 | 왜 필요한가요 |
|---|---|
| `activeTab` | 툴바 아이콘(또는 단축키)을 **누른 그 탭만**, 누른 그때에만 찍을 수 있게 합니다. 다른 탭이나 방문 기록은 볼 수 없습니다. |
| `scripting` | 찍는 동안 그 페이지를 스크롤하고, 고정 메뉴를 잠시 숨기고, 페이지 길이를 재는 작은 코드를 넣기 위해 필요합니다. 촬영이 끝나면 페이지를 원래대로 돌려 놓습니다. |
| `downloads` | 이미지와 PDF를 다운로드 폴더(또는 설정한 하위 폴더)에 저장하기 위해 필요합니다. |
| `storage` | 설정(파일 형식, 폴더 이름 등)을 기억하기 위해 필요합니다. |
| `unlimitedStorage` | 찍은 스크린샷을 이 컴퓨터 안에 넉넉히 보관하고, 디스크 공간이 부족할 때 크롬이 보관함을 자동으로 지우지 않게 하기 위해 필요합니다(아래 "보관 용량" 참고). |
| `clipboardWrite` | "복사" 버튼으로 이미지를 클립보드에 넣기 위해 필요합니다. |

"모든 사이트의 데이터 읽기·변경" 같은 넓은 권한은 요청하지 않습니다. 또 확장 프로그램 화면에는 인터넷 접속을 막는 보안 규칙(`connect-src 'self' data: blob:`)을 걸어, 프로그램이 바깥 서버와 통신할 수 없게 했습니다.

## 보관 용량 (스크린샷은 어디에, 얼마나?)

- 찍은 스크린샷은 크롬 안의 이 확장 프로그램 전용 저장소(IndexedDB)에 보관됩니다. 다른 사이트나 프로그램은 볼 수 없습니다.
- 크롬 공식 문서 기준:
  - 확장 프로그램 저장소는 기본적으로 웹사이트와 같은 용량 제한을 받고, **디스크 공간이 부족하면 자동으로 지워질 수 있습니다.** `unlimitedStorage` 권한을 요청하면 **용량 제한과 자동 삭제 모두에서 제외됩니다.** (출처: Chrome for Developers, "Storage and cookies" — https://developer.chrome.com/docs/extensions/develop/concepts/storage-and-cookies)
  - 참고로 같은 권한이 없을 때 `chrome.storage.local`의 기본 한도는 10MB(10,485,760바이트)입니다. 이 프로그램은 설정만 여기에 넣고, 이미지는 IndexedDB에 넣습니다. (출처: Chromium 확장 API 정의 `storage.json`의 `QUOTA_BYTES`)
  - 권한이 없을 때 웹 저장소는 한 사이트당 최대 디스크 전체 용량의 60%까지 쓸 수 있습니다. (출처: web.dev, "Storage for the web")
- 결국 이 프로그램은 **컴퓨터의 남은 디스크 공간만큼** 보관할 수 있습니다. 스크린샷 한 장은 보통 1~20MB입니다. 필요 없는 것은 "내 스크린샷"에서 지워 주세요.

## 촬영 방식에 대한 참고

- **촬영 속도**: 크롬은 확장 프로그램이 화면을 찍는 기능(`captureVisibleTab`)을 **1초에 최대 2번**까지만 허용합니다(Chromium API 정의 `tabs.json`의 `MAX_CAPTURE_VISIBLE_TAB_CALLS_PER_SECOND = 2`). 그래서 한 조각을 찍을 때마다 최소 0.55초(0.5초 + 여유 0.05초)를 띄웁니다. 긴 페이지는 수십 초가 걸릴 수 있습니다.
- **화면 배율**: 레티나 같은 고해상도 화면에서는 화면 배율(예: 2배)만큼 큰 이미지가 만들어집니다.
- **아주 긴 페이지**: 한 장의 높이가 16,384px를 넘으면 여러 장으로 나눠 보관합니다(결과 화면 위에 "1 / 3번째 부분" 단추가 나옵니다).
- **고정 메뉴**: 화면에 고정된 메뉴·배너는 첫 조각에만 찍히고, 다음 조각부터는 잠시 숨겨 반복되지 않게 합니다.
- **스크롤하면서 계속 늘어나는 페이지**(무한 스크롤): 촬영을 시작할 때의 길이까지만 찍습니다.

## 만들지 않은 기능

| 기능 | 이유 |
|---|---|
| Google Drive에 저장 | 구글 로그인 승인과 앱 등록이 필요하고, "인터넷으로 보내지 않음" 원칙과 맞지 않습니다(확정 방침). |
| 계정 로그인, 유료(Pro) 안내 | 모든 기능이 무료라 필요 없습니다(확정 방침). |
| 일괄 촬영, 증거 모드, 검색 가능한 PDF | 2단계 기능입니다. 요청하시면 만듭니다. |
| 결과 화면·내 스크린샷의 별 아이콘 | 기존 프로그램에서 무슨 기능인지 확인하지 못했습니다([`docs/OPEN_QUESTIONS.md`](docs/OPEN_QUESTIONS.md) Q38). |
| 화면 언어 선택 | 지금은 한국어만 있습니다. 문구를 `src/shared/i18n/ko.ts` 한 파일에 모아 두어 나중에 다른 언어를 더할 수 있습니다. |

문제를 발견하면 [이슈 페이지](https://github.com/yoosk526/full-page-capture-chrome/issues)에 알려 주세요. (프로그램 안의 깃발 아이콘 "문제 알리기"도 이 페이지를 엽니다.)

## 개발자용

| 명령 | 하는 일 |
|---|---|
| `npm install` | 개발 도구 설치 (클라우드 세션에서는 `.claude/settings.json`의 시작 훅이 자동으로 실행) |
| `npm run build` | 타입 검사 + `dist/`에 확장 프로그램 빌드 |
| `npm test` | 단위 테스트 (Vitest) |
| `npm run coverage` | 단위 테스트 + 커버리지(참고용) |
| `npm run test:doc` | 단위 테스트를 실행하고 `docs/TEST_CASES.md`를 다시 만든다 |
| `npm run e2e` | 화면 없는 Chromium에 `dist/`를 올려 촬영·편집·저장 흐름 확인 (`npm run build` 먼저, 결과 이미지는 `e2e/out/`). Chromium 경로는 `CHROMIUM_PATH`, 화면 배율은 `DPR` 환경 변수 |
| `npm run icons` | 아이콘 PNG 다시 만들기 |
| `npm run package` | 빌드 후 `release/hanjang-capture-v<버전>.zip` 만들기 (PR 직전에만) |

구조

- `src/core/` — Chrome API를 쓰지 않는 순수 계산(스크롤 계획, 분할, 자르기 보정, 실행 취소, 파일 이름, 주소 판별, 호출 간격, 복사본 축소, 번호 매기기, 도장 문구, PDF 만들기). 단위 테스트 대상
- `src/background/` — 서비스 워커: 촬영 진행, 이어 붙이기, 보관
- `src/content/` — 촬영하는 페이지에 넣는 코드(스크롤, 고정 요소 숨기기)
- `src/render/` — 편집 내용 그리기, PNG/JPG/PDF 만들기
- `src/pages/` — 팝업, 결과, 편집기, 설정, 내 스크린샷 화면
- `src/shared/` — 저장소(IndexedDB, chrome.storage), 화면 문구(i18n), 공통 UI
- `tests/` — 단위 테스트, `e2e/` — 브라우저 시험
- 문서: [`docs/FEATURES.md`](docs/FEATURES.md)(기능 명세), [`docs/TEST_CASES.md`](docs/TEST_CASES.md)(테스트 목록), [`docs/OPEN_QUESTIONS.md`](docs/OPEN_QUESTIONS.md)(질문), [`docs/MANUAL_TEST.md`](docs/MANUAL_TEST.md)(직접 확인 목록)
